# Ảnh gốc của bộ nhận diện (tuỳ chọn)

Bỏ 2 file PNG nền trong suốt vào đây để script dùng đúng ảnh gốc thay cho bản vẽ bằng code:

- `khung.png`: khung tiêu đề (tấm trắng viền xanh trên tấm nền xanh), tỉ lệ khoảng 2:1
- `ngoi-sao.png`: ngôi sao vàng mặt cười

Chưa có file thì script tự vẽ khung và ngôi sao giống mẫu.
